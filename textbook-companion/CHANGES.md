# Adaptations for companion use

The authored examples were selected for specific textbook mechanisms and retained as optional support. The course labs, datasets, assessment routes and numbering remain unchanged.

- Added one launcher that ignores inherited database targets, creates fresh private clusters and preserves each run in a new private output directory.
- Removed the earlier fixed-database deletion step; low-level harness entry points now require the companion launcher.
- Replaced fixed demonstration passwords with generated runtime values; renamed person-like login aliases to their demonstration roles.
- Added explicit checks of transaction, quality and analytical outcomes. A successful shell exit alone is insufficient.
- Require deliberate validator mutations to fail with the assertion-failure status rather than accepting any setup error.
- Retained only necessary code extracts, fixtures and references. Private reviews, working paths, full raw histories, document builders, superseded variants and third-party full texts are excluded.
- Added chapter navigation, scoped expectations, interpretation prompts, reusable blank records and aggregate reference evidence.

The examples retain their stated interval conventions and synthetic fixture populations. Companion execution checks do not establish a full manuscript citation audit, fresh OS installation, independent learner completion or production capability.
