# Private submissions

Use [the template](template.md) to create your own local submission file, or use
`.local/` as directed by the lab. Submit through the LMS or the instructor's
specified private channel. Leave the tracked template unchanged.

Only this README and the blank template are public. Other files under
`submissions/` are ignored by Git. Do not force-add them: ignore rules prevent
accidental additions, not deliberate publication. Do not publish student work
or personal information.
