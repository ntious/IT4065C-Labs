# Student project showcase

This page highlights student-created final projects from IT4065C: Data Technologies
Administration, taught by Isaac K. Nti. Projects illustrate how students apply
course concepts to their own designs, implementations and evidence.

The course framework is authored by Isaac K. Nti. Each linked student project is
credited to its student authors and remains in their repository under its own terms.
Please cite the students' project when reusing their work, and cite the course
repository when reusing the course materials.

## How to explore a project

For projects you are authorized to access, use the work as a case study rather
than an answer key:

1. Identify its problem, intended users and data sources.
2. Trace one design decision to its implementation and supporting evidence.
3. Examine its governance, lifecycle, modeling, access or monitoring choices.
4. Identify a limitation and explain how you would test an improvement.
